# 60-second demo

1. Open **https://anvilapi-2e7c-3000.prg1.zerops.app**
2. Hero: six microservices forge PDFs → click **Run live pipeline demo**
3. Watch job ticket + architecture nodes (api → bus → worker → store)
4. File downloads when status is **done**
5. Optional: **Compress Report** or **Images → PDF** (sample photo)
6. Flash Zerops dashboard: `anvilapi` `anvilworker` `anvildb` `anvilbus` `anvilcache` `anvilstore` green
7. Close: “API enqueues. Worker forges. Queue, cache, DB, and object storage — all Zerops.”

## Backup

If a live job is slow, open recent history / re-run demo; samples never require upload.
